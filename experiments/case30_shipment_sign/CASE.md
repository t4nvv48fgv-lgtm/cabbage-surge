# Case 30 — 월보의 '대상월 출하량 전망'을 생산 전망과 엮어 평시·경보 가르기

- 성격: 방안 케이스 → **2026-10-13 채택, 메인 5차 편입**(아래 판정).
- 사용자 제안(2026-10-13): "해당 월보에 그럼에도 출하량은 증가할 것이라는 전망도 있잖아? 그걸 엮어서 사인으로 만들 수 있나?"
- 계기: 2026년 8월호는 여름배추 생산 전망이 −0.9%인데 8월 출하량은 전년 대비 증가로 봤다. 현행 게이트는 생산 전망만 보고 0 이하이면 경보로 분류해 8월 가격을 +19% 높게 예측했다. 평시 모형이었다면 −3%였다.
- 주의: case14에서 월보의 출하량 전망은 쓰지 않기로 했었다(월보와 모형이 서로 맞물림). 이번에는 사용자가 직접 제안해 시험한다.

## 신호

- Q = 그 호가 전망한 **그 달 배추 출하량의 전년 대비 방향**(증가 +1, 비슷 0, 감소 −1).
- 2021년 6월호~2026년 9월호의 6~10월호 28개를 판독해 `krei_shipment_outlook_2021_2026.csv`에 문장과 함께 적었다. 월보 본문·표지·요약 쪽에서 읽었고, 2021년은 자문회의 원고에서 읽었다.
- 판독이 약한 곳: 2022년 10월호(평년 대비 표현만 있음), 2024년 10월호(요약 그림으로만 판단), 2025·2026년 6월호(표지에 표현 없음, 비워 둠), 2026년 10월호(미발간).
- 생산 전망 S와 Q 모두 그 달 말에 이미 쓰여 있는 다음 달 호를 본다(7월 말 → 8월호).

호별 값(S는 여름배추 생산 전망 전년비 %, Q는 출하량 전망 방향):

| 해 | 7월호 | 8월호 | 9월호 | 10월호 | 9월 가격 |
|---|---|---|---|---|---|
| 2021 | +7.3 / 증가 | +8.9 / 증가 | +6.5 / 증가 | +5.9 / 증가 | 평시 |
| 2022 | −8.6 / 감소 | −8.3 / 감소 | −10.4 / 감소 | −11.4 / 감소 | 급등 |
| 2023 | +5.1 / 증가 | +8.6 / **감소** | +9.4 / 증가 | +6.0 / 증가 | 평시 |
| 2024 | −4.3 / 감소 | −7.2 / 감소 | −6.6 / 감소 | −12.0 / 감소 | 급등 |
| 2025 | +11.9 / **감소** | +8.8 / 비슷 | +11.0 / 증가 | +4.5 / 증가 | 평시 |
| 2026 | −3.5 / **증가** | −0.9 / **증가** | −3.2 / 감소 | 미발간 | 평시 |

- 급등 해(2022·2024)는 여름 내내 생산 전망과 출하량 전망이 **둘 다 감소**였다.
- 두 신호가 엇갈린 호는 넷이다(굵은 글씨). 2026년 7·8월호가 "생산은 줄지만 출하는 는다"였다.

## 규칙

여름 원점(6~9월)에만 적용한다. 평시면 평시 모형, 경보면 대표 모형 × (1 − 0.566 × S/100)이고, 그 뒤 단계는 메인과 같다.

| 규칙 | 경보 조건 |
|---|---|
| 현행 | 생산 전망 ≤ 0 |
| 둘 다 감소 | 생산 전망 ≤ 0 **이고** 출하량 전망도 증가가 아님 |
| 하나라도 | 생산 전망 ≤ 0 **이거나** 출하량 전망이 감소 |
| 출하 우선 | 출하량 전망이 감소(비슷·미상이면 생산 전망으로) |

"둘 다 감소"가 사용자가 말한 엮는 방식이다(생산이 줄어도 출하가 늘 전망이면 평시).

### 읽는 법

- **"둘 다 감소"는 손해가 없다.** 월말은 2026년 두 원점만 바뀌고 둘 다 좋아진다(+11 → +3%, +19 → −3%). 2021~2025년 월말은 하나도 바뀌지 않아 급등 해 예측(2024-09 −6% 등)이 그대로다. 주간은 2021~2025년 14.99 → 15.01로 같고, 2026년까지 넣으면 15.85 → 15.48이다.
- 주간에서 바뀌는 원점은 13개다. 2026년 8월 원점 5개는 넷이 좋아지고(+15 → −4%, +32 → +21% 등), 2026년 7월 4개와 2024년 6월 4개는 반반이다.
- **"하나라도"와 "출하 우선"은 주간에서 나빠진다**(14.99 → 16.3). 2023년 8월 주간 원점들이 경보로 바뀌면서 +18 → +62%, +38 → +61%로 크게 틀린다. 생산이 늘 전망인 해에 출하량 감소 문장 하나로 경보를 켜면 안 된다는 뜻이다.
- 그래서 쓸 만한 것은 **"생산 전망이 줄 때, 출하량 전망까지 줄어야 경보"** 하나다. 출하량 전망은 경보를 끄는 쪽으로만 쓴다.

## 한계

- **월말에서 바뀌는 것은 2026년뿐이다.** 이 규칙은 2026년 8월 오차를 보고 떠올린 것이라, 2026년에서 좋아지는 것은 검증이 아니다. 2021~2025년에는 두 신호가 "생산 감소 + 출하 증가"로 엇갈린 월말 원점이 없어서 확인할 표본이 없다. 주간의 2024년 6월 4개 원점(생산 −2.9, 출하 증가)이 유일한 과거 사례이고 결과는 반반이다.
- 출하량 전망은 문장의 방향만 읽은 것이다. 증감률이 본문에 있는 호는 일부라 크기는 쓰지 않았다.
- 2016~2020년은 판독하지 않았다. 그 구간은 생산 전망 게이트 자체가 맞지 않아(case13·22) 메인이 신호를 쓰지 않는다.
- 월보의 출하량 전망은 월보의 가격 전망과 같은 표에서 나온다. 이 신호를 쓰면 모형이 월보 판단에 더 기대게 된다.

## 판정

**채택 — 메인 5차 편입(2026-10-13, 사용자 결정 "case30 채택").** "둘 다 감소"만 넣었다.

- 메인 반영: `src/gate_model.py`가 `data/ext/krei_shipment_outlook.csv`(이 폴더 판독표의 복사본)를 읽어 열 `ship_q`로 붙이고, 여름 원점의 평시 판정을 `S1 > 0 또는 ship_q > 0`으로 바꿨다. `src/forecast_live.py`도 같은 규칙.
- 편입 뒤 값: 월말 2021~2025 11.38%(불변), 2021~2026 11.08 → 10.72%, 주간 2021~2025 15.14 → 15.15%, 2021~2026 14.87 → 14.75%. 2026-06-30 +10.9 → +3.4%, 2026-07-31 +19.2 → −2.5%.
- 종전 규칙의 값은 `outputs/gate_predictions*.csv`의 참고 열 `final_prod_only`에 남는다. 이 스크립트의 "현행"은 그 열과 맞춘다.
- 새 호가 나오면 메인 판독표(`data/ext/krei_shipment_outlook.csv`)에 한 줄 추가한다. 2026년 10월호는 아직 없어 9/30 원점은 9월호(생산 −3.2, 출하량 감소 → 경보)를 본다.
- 아래 권고·걸리는 점은 채택 전에 적은 것이고 단서로 그대로 유효하다.
- **왜 2026년 7·8월호가 "생산 감소 + 출하량 증가"였나(2026-10-13 사용자 설명, 월보 담당자): 봄배추 저장량 증가 영향이 크다.** case07 자료와 맞는다 — 대량수요처 저장 계획량 46,983t(전년 +10.1%), 8월 가락 반입의 31%가 저장배추(2024년 12%, 2025년 44%). 저장분 출하는 해마다 9월 둘째 주에 끝나고, 9월호는 출하량 '감소'로 돌아섰다. 여름배추 생산 전망에는 저장분이 없으므로, 이 규칙에서 출하량 전망은 그 저장분을 받아들이는 통로다. 저장량 수준만으로는 급등을 못 가른다는 case07 판정(2024년 반례)은 그대로다.

- 권고: "둘 다 감소"를 넣는다면 2021~2025년 성적과 성공 기준 달은 그대로이고, 2026년 같은 "생산은 소폭 감소인데 출하는 는다"는 해에서 과대 예측을 막는다. 손해가 확인된 곳이 없다.
- 걸리는 점: 근거가 사실상 2026년 한 해이고, case14의 "출하량 전망 미사용" 결정을 바꾸는 일이다.
- 넣으면 달라지는 값: 2026-06-30 +11 → +3%, 2026-07-31 +19 → −3%. 월말 2021~2026 11.08 → 10.72%. 2026년 10월 전망(9/30 원점)은 10월호의 출하량 전망 방향을 알아야 정해진다.
