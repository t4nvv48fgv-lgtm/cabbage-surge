# Case 09 — 학습으로 조절되는 분위수 수준 (공급 신호 → Chronos-2 분위수 τ 를 자료에서 배우고 해마다 갱신)

- 성격: **아이디어 케이스**. 메인 `src/`·README 결과표를 바꾸지 않는다. 메인 산출물(`outputs/backtest_predictions*.csv`, `anomaly_predictions*.csv`)과 case05·case06 함수는 읽기·import만.
- 날짜: 2026-10-12. 사용자 제안 두 단계: (1) "KREI 발표치·저장배추 자료를 트리거로 써서 임계 이상/이하에서 아예 다른 기울기를 적용하자(물의 상전이처럼)" → (2) "분위수를 강제하지 말고 학습으로 조절되게, 새 해 자료가 들어올 때마다 갱신되게".
- 선행: case01(손으로 정한 상수로 심각도 → 분위수 0.5→0.9), case06 G_K(임계 S1 ≤ 0 으로 대표 ↔ 평시 전환). 둘 다 급등 국면의 분위수·모형을 사람이 정한다.

## 아이디어

과거 원점마다 실제값이 Chronos-2 예측분포의 몇 번째 분위수에 떨어졌는지(**τ\***, PIT)를 구한다. 공급 신호 S → τ\* 의 사상을 **그 원점 이전에 타깃 창이 닫힌 원점만으로**(확장 창) 적합하고, 그 원점의 점예측은 Chronos-2 분위수를 학습된 τ̂ 에서 읽는다. 새 해가 끝나면 그 해의 (S, τ\*)가 학습 표본에 더해져 사상이 갱신된다.

```
τ*(o)  = 실제(o) 가 Chronos-2 분위수 {0.01,0.05,0.1,…,0.9,0.95,0.99} 중 어디에 떨어지는지 선형보간 (범위 밖은 0.01/0.99)
학습 표본 T(o) = { o' : target_end(o') ≤ o, 여름 원점(6~9월), 신호 있음 }          ← 누수 없음
lin    τ̂ = a + β·z,  z = 표준화 S,  a = 학습 τ* 평균을 0.5 쪽으로 k 수축(절편 없음 변형은 0.5 고정),
       β = ridge(alpha=k)·부호 제약 β ≤ 0 (신호가 낮을수록 τ 높음).  k 는 가상 관측 수(Σz² ≈ n 이라 β 가 n/(n+k) 배 수축)
iso    단조 감소 isotonic 회귀 → τ̂ = (n·iso(S) + k·0.5)/(n+k)
범위   scope=summer: 과거 여름 원점 전부 / scope=month: 같은 달 원점만(8월 말 원점은 과거 8월 말 원점만 = "8월 발표치 → 9월 가격")
학습 표본 < n_min(3) 이면 τ̂ = 0.5.  비여름·신호 없는 원점 τ̂ = 0.5.  LQh_* = 여름은 학습 분위수, 비여름은 대표 모형(an_sparse_all)
```

신호: **S1** KREI 월보 여름배추 생산량 전망 전년비(원점까지 발행된 최신호, case06 함수 재사용, 2021~2026) / **S2** 정부비축 잔량 추정(case05, 2017~2026, 천 톤) / **S12** 둘 다(lin 은 2변수 ridge, iso 는 두 τ̂ 평균).
손 상수는 수축 강도 k(기본 2)와 n_min(3)뿐. 둘 다 민감도 표에 보고. 비교 대상: Chronos-2 중위수, 대표 모형, G_K(case06 규칙 재계산, 값 동일), case01 연속 트리거.

## 데이터 사실

- Chronos-2 분위수는 `outputs/chronos_quantiles*.csv` 에 캐시(0.01~0.99 13단계, 향후 h스텝 평균의 분위수 근사 — case01 과 같은 방식). q50 은 메인 `chronos2` 와 소수점까지 일치(차이 0.00%).
- 월보 호별 여름배추 전망치(S1 원천)는 `outputs/krei_issues.csv` 로 저장 → 판독표(`data/local`, 비공개) 없이 재현 가능.
- **τ\* 에는 원점 달의 계절 구조가 있다**(월말, 2017~2026 여름 원점 평균): 6월 0.60, 7월 0.68, **8월 0.67**, 9월 0.47. Chronos-2 중위수가 6~8월 원점에서는 계절 상승을 과소, 9월 원점에서는 하락을 과대한다는 뜻. 여름 풀로 학습하면 이 구조가 공급 신호보다 크다(예: 2022-07-31 S1 −8.6 인데 τ\* 0.23, 2023-07-31 S1 +5.1 인데 τ\* 0.92).
- 8월 말 원점의 τ\*: 2021 0.56 / 2022 **0.90** / 2023 0.35 / 2024 **0.83** / 2025 0.74 / 2026 0.36. 급등 해가 높지만, 급등 없는 2025 도 0.74(Chronos 중위수 −13% 과소였기 때문). 2024 실제는 q99 안(q90 26,250 > 24,714).

## 판정

- **지지되지 않음(이 자료 규모에서).** 같은 달 선형 사상이 2024 를 −7~−8% 로 잡아 대표 모형(−10%)보다 조금 낫지만, (a) 2022 는 학습 표본 1개라 못 잡고(−32%), (b) 2026 표본외에서 +19~+22% 거짓 경보를 내며(G_K −6%), (c) 2021~2025 MAPE 15.1~15.2% 로 G_K(13.8%)에 못 미친다. 성공 기준 두 항 어느 쪽도 G_K 보다 낫지 않다.
- **원인 1 — 학습 대상이 혼합물이다.** τ\* 에는 "공급 국면" 외에 Chronos-2 의 계절 편향(8월 원점 평균 0.67)과 해마다 다른 분포 폭이 섞여 있다. 사상이 먼저 배우는 것은 공급 신호가 아니라 그 편향이고, 편향이 뒤집힌 해(2026)에 그대로 틀린다. 여름 풀로 넓히면 월별 계절 구조가 신호를 덮는다(β −0.04~−0.07, τ̂ 0.45~0.60 에서 거의 안 움직임).
- **원인 2 — 점이 3~5개.** 같은 달 범위에서 S1 은 2024 에 3점, 2026 에 5점. 학습된 사상은 사실상 "±8 두 덩어리를 잇는 직선" 이라 중간값(−0.9)을 해석할 근거가 없다. S2 는 2017·2019 예외(잔량 적은데 급등 없음 / 많은데 태풍 급등) 때문에 β≈0 으로 수축돼 절편만 남는다.
- **원인 3 — 이진 신호에는 임계 규칙이 이미 최선이다.** S1 의 2021~2025 값은 {+8.9, −8.3, +8.6, −7.2, +8.8} 로 두 덩어리다. 이런 분포에서 연속 사상이 임계 규칙(G_K)보다 더 배울 것이 없고, 대신 학습 노이즈와 편향 절편을 떠안는다. 연속 사상의 이점(중간값 처리)은 중간값이 있는 해가 여러 개 쌓인 뒤에야 생긴다.
- 사용자의 상전이 비유에 대한 답: 국면 판정(트리거)은 자료가 뒷받침하고 G_K 가 이미 그 역할을 한다. "급등 국면의 다른 기울기" 는 **Chronos-2 분위수로는 표현이 모자란다** — 급등 해 8월 말 τ\* 0.83~0.96 이고 2020 은 q99 근처라, 급등 국면에서 필요한 것은 분위수 상향이 아니라 분포 자체가 다른 모형(급등 해만으로 학습한 모형 또는 평년 × 급등 배율)이다. 그 실험은 이 케이스 범위 밖(다음 후보).

## 한계

- 이 케이스가 "학습이 안 된다" 를 보인 것은 Chronos-2 분위수 + 6~10개 해 조건에서다. 다른 기반 분포(계절편차 ridge 의 분위수 회귀)나 더 긴 신호(2010~ 잔량·월보)에서는 결론이 다를 수 있다.
- S2 는 lin 에 천 톤 원값을 넣었다(로그·절단 변환은 손 상수를 더하므로 피함). 2026 12,014t 같은 큰 값이 표준화에 영향.
- 2017~2020 여름 지표는 S1 없음·S2 만이라 참고용.
