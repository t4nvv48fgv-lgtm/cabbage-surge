# Case 02 — 가용 데이터 전부를 피처로 쓴 피팅

- 성격: **비교 실험 케이스**. 메인 모형(`src/`)·메인 결과표(README "1차 결과")·평가 설계는 바꾸지 않는다. 메인은 import·읽기만 한다.
- 날짜: 2026-10-07 실행, 2026-10-08 케이스로 분리(메인 `build_features.py`에 넣었던 확장 블록도 이 폴더 `case_features.py`로 옮기고 메인은 원복).
- 사용자 요청: "가용한 데이터들을 다 사용해서 한번 피팅해볼래?"

## 설계

평가 설계(원점 집합·타깃 향후 28일 평균가격·누수 차단·하이퍼파라미터)는 메인 `backtest.py`/`anomaly_model.py`와 동일하게 두고 **피처만 늘린다**.

추가 피처 (`case_features.py` → `outputs/daily_features_ext.csv`, 메인 98열 + 33열)

| 묶음 | 열 | 출처·주의 |
|---|---|---|
| 등급별 가격비 | spread_* 5개(메인에 있으나 기본 제외였던 것 재포함) | garak_daily |
| 정부 매입 | govpur30/60, govpur_avail | at_gov_daily 2021~. 그 이전은 결측이 아니라 0 → 트리가 "2021 이후" 더미로 쓸 수 있음 |
| 작형별 생산량 | lprod_lag1y, dprod_lag1y | produce.csv(통계청 연간). 당해년 값은 수확 후 공표 → 365일 lag만(누수 방지) |
| 반입량 | lq90, qyoy7 | clean_daily |
| 고랭지 90일 누적 | H_hot30_sum90 등 4개 | 생육기 전체 폭염·강수 |
| 준고랭지(영월) | M_* 12개 | 2기작 대리 |
| 전체 관측소 평균 | A_* 10개 | 117일짜리 3개소 제외 |

쓰지 못한 데이터와 이유: KREI 월보 단수·생산량 전망(2022~2025년 3·5·6·10·12월호만 → 학습 기간 미포함, 8월말 원점에 쓸 수 있는 최신호는 6월호 −2.9%),
guide.csv(2023~2025 수급조절 기준선, 값 오류 많음), 일조시간(스냅숏에서 거의 전부 0), history.csv 정부매입(2021~만 → at_gov와 동일).

모형: all_ridge(= wx_ridge 구조, alpha 10, summer 상호작용) / all_hgb(= wx_hgb 하이퍼) / all_lgbm / all_anom_ridge(= an_ridge_all 구조) / all_anom_sparse / chronos2_cov(Chronos-2 제로샷 + 과거 공변량 9개).

## 결과 (월말 원점, 2021~2025 n=60; 기존 모형은 메인 저장값을 같은 원점에서 병합)

| 모형 | 2024-09 | 2025-08(급등 없음) | 2022-08 | MAE | MAPE | bias |
|---|---|---|---|---|---|---|
| 가격만 ridge (메인 기준) | −37% | −9% | −33% | 1,700 | 15.1% | −1,191 |
| 기상 HGB (메인 최선) | −27% | +9% | −33% | 1,583 | 14.0% | −971 |
| all ridge | −34% | +34% | −63% | 2,366 | 21.9% | −609 |
| all HGB | −27% | +15% | −37% | 1,609 | 14.5% | −982 |
| **all LightGBM** | −31% | +9% | −33% | **1,553** | **13.9%** | −984 |
| all 계절편차 ridge | **−4%** | **+35%** | **−62%** | 2,008 | 19.5% | −518 |
| all 계절편차 희소 | −12% | +26% | −57% | 1,821 | 17.6% | −481 |
| Chronos-2+공변량 | −17% | +21% | −36% | 1,968 | 19.4% | −612 |

여름 원점(n=20) MAPE: all LightGBM 14.8%(최선), 기상 HGB 17.6%, Chronos-2 19.7%.

## 판정

- **두 성공 기준을 동시에 만족하는 모형 없음.** 2024-09 −10% 이내는 all 계절편차 ridge(−4%)만 달성했으나 MAPE 19.5%로 기준보다 나쁘고 2025-08 +35%, 2022-08 −62%. 전체 지표 최선 all LightGBM(13.9%)은 2024-09 −31%.
- **−4%는 다중공선성의 우연한 상쇄.** 2024-08-31 기여 분해: 전체 관측소 폭염일 +0.90, 준고랭지 폭염일 −0.34/−0.34, 고랭지 폭염일 −0.29. 같은 방향 변수들이 반대 부호로 상쇄. 성과로 쓰지 않는다.
- **90일 누적 폭염은 2025년(57일)이 2024년(54일)보다 많다**(90일 기온편차도 +2.99 > +2.54°C). 폭염 누적량만으로는 급등 해와 비급등 해를 가르지 못한다.
- 피처를 늘리면 선형은 급격히 나빠지고(21.9%) 트리는 조금 좋아진다(13.9~14.5%). Chronos-2 공변량은 무효(2024-09 −17% vs 제로샷 −18%, MAPE 악화).
- 결론: **병목은 데이터 양이 아니라 2024와 2025를 가르는 변수의 부재.** 후보는 산지 작황·정식 지연(준고랭지 2기작)·재배면적처럼 CABIS 스냅숏에 없는 정보. 피처 추가 방향은 중단.
- 파생: 이 결론이 case01(비축 방출 소진 트리거)로 이어졌다.

## 승격 조건 (메인에 넣으려면)

1. 2024·2025를 가르는 외생 변수가 들어와 계절편차 모형의 상쇄 구조 없이 2024-09 −10% 이내가 나올 때.
2. all LightGBM을 메인 지표 모형으로 올리려면 2016~2023 설계·2024~2025 검증 분리에서 기상 HGB 대비 개선이 유지되는지 확인(현재 0.1%p 차이는 실행 간 변동 ±2~3%p 안).
3. 정부 매입·방출 피처는 at_gov 출처(2021~)의 가용 더미를 동반하는 형태로 메인 피처 설계 승인.

