# cabbage-surge — 2024년 9월 배추 급등 추종 예측모형

CABIS와 분리된 독립 실험 저장소. 목표는 KREI 두 연구(Chronos-2 파운데이션 모형, STL 분해-예측조합)가
공통으로 놓친 **2024년 9월 급등**(가락 상품 월평균 24,700원/10kg, 전월 대비 +45%)을 따라가는 모형.

## 구조

```
src/build_features.py   일별 피처 프레임 (정보집합 = 원점 당일까지). 타깃 = 향후 28일 평균가격
src/backtest.py         롤링 원점 백테스트 (M=월말, W=매주 일요일). SURGE_BASE=lp28|lp7
src/ts_baselines.py     단변량 시계열 기준모형: Chronos-2 제로샷, MSTL+AutoARIMA/AutoETS (KREI 두 연구 계열 재현)
src/anomaly_model.py    계절 정상치 편차 모형 (급등 외삽용 희소 선형) — 게이트의 대표(경보) 모형
src/gate_model.py       최종 모형(2026-10-12 편입): 대표 an_sparse_all + KREI 월보 생산 전망 게이트(S1 ≤ 0 → 경보 유지) + 평시 wx_hgb_summer
                        + 겨울 분기(대상월 1~4월 = 겨울 작형 학습 가격만 ridge) + 잔차 β 층(여름 경보·가을 생산 전망 수준 조정) — 2026-10-12 2차 편입, 열 final
src/plot_2024.py        2024 여름 주간 추적 그래프
tools/make_report.py    쉬운 말 결과 보고서 PDF / tools/make_model_guide.py  최종 모형 설명서 PDF
data/ext/krei_summer_issues.csv  KREI 월보 호별 여름배추 전망(게이트 신호·여름 경보 조정 원천, 2021~)
data/ext/krei_nonsummer_issues.csv  KREI 월보 호별 겨울·봄·가을배추 전망(가을 행만 잔차 β 층에 사용, 2021~)
experiments/caseNN_*/   메인을 바꾸지 않는 아이디어 케이스 (각 CASE.md 참조)
outputs/                예측·지표 CSV, 그림
```


### 2차 편입 (2026-10-12, case15·case16 승격, 사용자 결정 "둘 다 적용") — 열 `final`

```
대상월(원점+15일의 달) 1~4월      →  겨울 작형 학습 가격만 ridge (winter_ridge; 게이트를 대체)
여름 경보 원점(게이트가 대표 선택) →  게이트 예측 × (1 − 0.566 × S/100),  S = 여름배추 생산 전망 전년비(S ≤ 0)
대상월 11~12월                    →  게이트 예측 × (1 − 0.216 × S/100),  S = 가을배추 생산 전망 전년비(없으면 면적), |S| ≤ 20
그 외(봄 5~6월, 여름 평시, 10월 대상) →  게이트 예측 그대로
```

β(−0.566·−0.216)는 2016~2020 원점에서 log(실제/게이트 예측)을 생산 전망에 회귀한 **잔차 반응**(case16 사전 설계판), 겨울 ridge는 2016~2020 설계 창과 2021~2025 검증 창에서 모두 겨울 1~2위였던 유일한 작형 조각(case15). 조정에 쓰는 S는 규약 B(m월호는 (m−1)월 말일부터 가용), 게이트 상태 판정은 종전 그대로.

|---|---|---|---|---|---|
| 2021 | 평시 | – | 0 | +2% | **+2%** |
| 2022 | 경보 | 9월호 −10.4 | +5.9% | −16% | **−11%** |

| 2026 (표본외) | 경보 | 9월호 −3.2 | +1.8% | −6% | **−4%** |

단서(2차 편입분): (1) **주간 원점에서는 겨울 분기가 손해다**(겨울 11.6→12.1%, 전체 15.15→15.31%). 2016~2020 주간은 18.4→17.0%로 이득이라 창마다 방향이 갈린다. 주간 전체의 소폭 개선(15.15→15.10%)은 잔차 β에서만 온다. (2) **오차 30% 초과 달이 늘어난다**(2021-01~2026-09 대상월 69개 중 4→6개): 2021-01 −26→−32%(겨울 ridge가 저가 바닥에서 반등을 더 못 봄), 2022-08 +26→+32%(경보 조정이 이미 과대인 달을 더 올림). 20% 초과 달은 17→13개로 준다. (3) 잔차 β는 경보 달을 일괄로 올리는 층이라 봉우리 뒤 달(모형이 이미 과대인 달)은 나빠진다. (4) 두 부품은 각각 2016~2020에서 정했으나 함께 얹기로 한 결정은 2021~2025 결과를 본 뒤다. (5) 급등 해 수치가 대표 모형 값에서 달라지므로(2024-09 −9.5→−6.1%) 이전 문서의 "−10%"는 게이트 단계 값이다.

## 설계 요점

- **타깃**: log(향후 28일 평균가격) − 기준점. 월말 원점이면 익월 평균과 거의 같음.
- **고랭지 기상**: 평창(AWS 526)·태백(216)·정선군(217)·강릉(105) 평균. 2010~2019 일자별 평년 대비 편차,
  30°C 이상 일수, 폭염일, 열대야, 50mm 이상 강우일, 강수 편차 (7/14/30/60일 창).
- **수급**: 반입량 전년비, 모멘텀. 정부 방출 30/60일 합은 **2026-10-08 제외**(stock.csv 방출이 2022~만 있어 학습구간이 0으로 채워지고
  2022-08 첫 등장 때 선형 모형 외삽 사고를 일으킴. 아래 결과표 주석과 `wiki/risk-audit.md` R-2 참조).
- **계절 정상치 모형**: 직전 5년 같은 창의 평균을 정상치로 두고 편차를 예측. 선형·약한 규제.
  **2026-10-12 정정(case10 기여 분해)**: 이 모형의 2024-09 −10%는 폭염 피처가 아니라 `cur_anom7`(8/31 가격의 평년 대비 편차가 지속된다는 항, +0.25)에서 온다.
  8월 말 2024·2025의 기상 순기여는 ≈0(기온 +0.07을 강수 편차 −0.07이 상쇄). 가격만 ridge(−37%)와의 차이는 기준점(평년치 vs 최근 28일 평균)이다. 기상 피처가 일하는 해는 2022(강수 +0.13)·2023.
- 누수 방지: 학습 표본의 타깃 창 종료일 ≤ 원점. 평가는 2016~2025 확장창.

### 단변량 기준모형(Chronos-2·MSTL)에서 알게 된 것

- 2010~ 월평균 시계열만 보는 Chronos-2 제로샷·MSTL이 2024-09를 −13~−18%로 따라간다. 가격만 ridge −37%는 "가격 정보의 한계"가
  아니라 **lp28 기준점 + 강한 규제가 평균회귀로 끌어당긴 결과**였다. 8월 하순 상승 모멘텀을 추세 외삽하는 모형은 급등 절반 이상을 잡는다.

   기상 피처가 일하는 해는 2022(강수 +0.13, −24%→−16%)·2023. 기상 ridge·HGB(−24~−26%)가 가격만 ridge(−37%)보다 나은 것도 같은 구조(평년 대비 편차 피처)의 효과로 봐야 한다.
   2026-10-09부터 계절편차 대표 사양은 `experiments/case03`에서 2016~2023 원점만으로 고른 것(SPARSE·전체 학습·alpha 10)이라 "2024를 보고 맞췄다"는 반박(R-1)을 넘는다.
   **2026-10-12 최종 모형**: 그 위에 KREI 월보 생산 전망 게이트(S1 ≤ 0 → 경보 유지)와 평시 여름특화 HGB를 얹어 2021~2025 MAPE 13.2%(case06·case10 승격).
