# cabbage-surge — 2024년 9월 배추 급등 추종 예측모형

CABIS와 분리된 독립 실험 저장소. 목표는 KREI 두 연구(Chronos-2 파운데이션 모형, STL 분해-예측조합)가
공통으로 놓친 **2024년 9월 급등**(가락 상품 월평균 24,700원/10kg, 전월 대비 +45%)을 따라가는 모형.

## 데이터 (data/raw — CABIS 스냅숏, 읽기 전용 복사 2026-10-06)

| 파일 | 원본 | 내용 |
|---|---|---|
| clean_daily.csv | CABIS market/ | 가락 일별 상품가격(원/10kg)·반입량(톤) 2010~2026.06 |
| garak_daily.csv | CABIS app/data | 등급별(특/상/중/하) 일별 가격 2005~ |
| weather_auto_daily.csv | CABIS app/data | 19개 관측소 일별 기상 2010~2026.08 |
| stock.csv | CABIS app/data | 정부 방출량 일별 2005~ |
| history.csv, at_gov_daily.csv, produce.csv, guide.csv | CABIS app/data | 여름 수급·정부 매입/방출·월별 생산량·수급조절 가이드 |
| krei_baechu_monthly_series_2022_2025.xlsx | CABIS market/outputs | KREI 월보 가격 동향/전망, 작형별 면적·단수·생산량 |

CABIS 원본은 수정하지 않는다. 갱신이 필요하면 CABIS에서 수집 후 다시 복사.

## 구조

```
src/build_features.py   일별 피처 프레임 (정보집합 = 원점 당일까지). 타깃 = 향후 28일 평균가격
src/backtest.py         롤링 원점 백테스트 (M=월말, W=매주 일요일). SURGE_BASE=lp28|lp7
src/ts_baselines.py     단변량 시계열 기준모형: Chronos-2 제로샷, MSTL+AutoARIMA/AutoETS (KREI 두 연구 계열 재현)
src/anomaly_model.py    계절 정상치 편차 모형 (급등 외삽용 희소 선형)
src/plot_2024.py        2024 여름 주간 추적 그래프
experiments/caseNN_*/   메인을 바꾸지 않는 아이디어 케이스 (각 CASE.md 참조)
outputs/                예측·지표 CSV, 그림
```

실행:

```bash
python src/build_features.py
python src/backtest.py M        # 월말 원점 (KREI 익월 전망과 비교 가능)
python src/backtest.py W        # 주간 원점
python src/anomaly_model.py M
python src/anomaly_model.py W
python src/plot_2024.py
```

## 설계 요점

- **타깃**: log(향후 28일 평균가격) − 기준점. 월말 원점이면 익월 평균과 거의 같음.
- **고랭지 기상**: 평창(AWS 526)·태백(216)·정선군(217)·강릉(105) 평균. 2010~2019 일자별 평년 대비 편차,
  30°C 이상 일수, 폭염일, 열대야, 50mm 이상 강우일, 강수 편차 (7/14/30/60일 창).
- **수급**: 반입량 전년비, 모멘텀. 정부 방출 30/60일 합은 **2026-10-08 제외**(stock.csv 방출이 2022~만 있어 학습구간이 0으로 채워지고
  2022-08 첫 등장 때 선형 모형 외삽 사고를 일으킴. 아래 결과표 주석과 `wiki/risk-audit.md` R-2 참조).
- **계절 정상치 모형**: 직전 5년 같은 창의 평균을 정상치로 두고 편차를 예측. 선형·약한 규제라
  2024-08의 학습범위 밖 폭염(+3.5°C, 30일 중 24일 30°C↑)을 외삽할 수 있음. 트리 모형은 범위 밖에서 평탄.
- 누수 방지: 학습 표본의 타깃 창 종료일 ≤ 원점. 평가는 2016~2025 확장창.

### 단변량 기준모형(Chronos-2·MSTL)에서 알게 된 것

- 2010~ 월평균 시계열만 보는 Chronos-2 제로샷·MSTL이 2024-09를 −13~−18%로 따라간다. 가격만 ridge −37%는 "가격 정보의 한계"가
  아니라 **lp28 기준점 + 강한 규제가 평균회귀로 끌어당긴 결과**였다. 8월 하순 상승 모멘텀을 추세 외삽하는 모형은 급등 절반 이상을 잡는다.
- 대신 추세 외삽은 비용이 크다. 2025-08(급등 없던 해) MSTL +32~35%, 2024-10 하락 전환 +45~60%. 전체 MAPE도 17.9~20.9%로 가격만 ridge(15.1%)보다 나쁘다.
- 기상 모형의 실제 기여를 재평가해야 한다. 계절편차 희소(사전선택) −10%(사후 여름 사양 −6%)는 MSTL+ETS −13%와 같은 수준이고, 급등 없던 해 과대(+21~+28%)는 MSTL(+32%)보다 작지만 가격만 ridge(−9%)보다 훨씬 크다.
  다음 비교의 기준선은 가격만 ridge가 아니라 Chronos-2·MSTL이어야 한다.

## 알게 된 것

1. lp28 기준 가격만 ridge는 9월 급등을 못 따라감(−37%). 단, 같은 가격 정보로도 추세 외삽형 단변량 모형(Chronos-2 제로샷 −18%, MSTL+ETS −13%)은
   절반 이상 잡는다 → 한계는 '가격 정보'가 아니라 '평균회귀 구조'에 있음. 2026-10-06 기준모형 추가로 수정된 결론.
2. 고랭지 폭염 피처가 가장 큰 개선(−37% → 대표 사양 −10%, 사후 사양 −6%, ridge·HGB −24~−26%). 2024-08은 학습 데이터 범위 밖이라 외삽 가능한 선형 구조가 유리.
   2026-10-09부터 계절편차 대표 사양은 `experiments/case03`에서 2016~2023 원점만으로 고른 것(SPARSE·전체 학습·alpha 10)이라 "2024를 보고 맞췄다"는 반박(R-1)을 넘는다.
3. 상품/중품 가격비(품위 신호)는 2024년엔 9월에야 벌어져 선행성 없음. 기본 피처에서 제외.
4. 남은 과소 −10%는 (a) 생산량 충격의 비선형(탄력성), (b) 준고랭지 2기작 정식 지연 같은 산지 정보 부재가 원인으로 추정.
5. **2026년 9월 표본외(2026-10-09)**: 서늘한 여름(고랭지 60일 폭염일 32.8, 30일 기온편차 −0.8°C; 2024는 40.5·+3.5°C, 2025는 43.8·+3.0°C)에 급등 없음(12,843원).
   대표 모형 −6%, 가격만 ridge −21%, Chronos-2 +10%. **거짓 경보는 폭염 피처가 켜진 해(2025)에만 나고 폭염 없는 해(2026)에는 나지 않는다**는 첫 표본외 증거. 평년치(15,892원)는 여전히 부풀어 있었지만 모형이 −19%로 깎아 맞췄다. 단 1건이므로 사례로만 서술.
6. **정부 방출 피처(gov30/gov60)는 자료 아티팩트였다(2026-10-08).** stock.csv 방출은 2022~만 있고 수집 누락이 0으로 들어가 2016~2021 학습구간이 전부 0.
   2022-08 첫 등장 때 선형 모형이 외삽 사고를 내 "기상 ridge 2022-09 −59%, 계절편차 ridge −52%"라는 가짜 실패를 만들었다. 제외하면 −31%·−12%, MAPE 17.2→15.0%·16.3→15.6%.
   트리와 2024-09는 영향 없음. 교훈: **5개년짜리 자료를 2016~ 학습 피처로 넣지 않는다.** 정부 방출의 쓸모는 `experiments/case01`의 2021~ 트리거로 한정.
