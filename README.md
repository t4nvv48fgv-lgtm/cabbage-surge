# cabbage-surge — 2024년 9월 배추 급등 추종 예측모형

CABIS와 분리된 독립 실험 저장소. 목표는 KREI 두 연구(Chronos-2 파운데이션 모형, STL 분해-예측조합)가
공통으로 놓친 **2024년 9월 급등**(가락 상품 월평균 24,700원/10kg, 전월 대비 +45%)을 따라가는 모형.

## 데이터 (data/raw — CABIS 스냅숏, 읽기 전용 복사 2026-10-06)

| 파일 | 원본 | 내용 |
|---|---|---|
| clean_daily.csv | CABIS market/ | 가락 일별 상품가격(원/10kg)·반입량(톤) 2010~2026.06 |
| garak_daily.csv | CABIS app/data | 등급별(특/상/중/하) 일별 가격 2005~ |
| weather_auto_daily.csv | CABIS app/data | 19개 관측소 일별 기상 2010~2026.08 |
| stock.csv | CABIS app/data | 정부 방출량 일별 2005~ |
| history.csv, at_gov_daily.csv, produce.csv, guide.csv | CABIS app/data | 여름 수급·정부 매입/방출·월별 생산량·수급조절 가이드 |
| krei_baechu_monthly_series_2022_2025.xlsx | CABIS market/outputs | KREI 월보 가격 동향/전망, 작형별 면적·단수·생산량 |

CABIS 원본은 수정하지 않는다. 갱신이 필요하면 CABIS에서 수집 후 다시 복사.

## 구조

```
src/build_features.py   일별 피처 프레임 (정보집합 = 원점 당일까지). 타깃 = 향후 28일 평균가격
src/backtest.py         롤링 원점 백테스트 (M=월말, W=매주 일요일). SURGE_BASE=lp28|lp7
src/ts_baselines.py     단변량 시계열 기준모형: Chronos-2 제로샷, MSTL+AutoARIMA/AutoETS (KREI 두 연구 계열 재현)
src/anomaly_model.py    계절 정상치 편차 모형 (급등 외삽용 희소 선형)
src/all_data_model.py   가용 데이터 전부를 피처로 쓴 변형 (ridge/HGB/LightGBM/계절편차/Chronos-2+공변량), 기존 결과와 같은 원점에서 병합 비교
src/trigger_quantile.py 비축 방출 소진 트리거 → Chronos-2 분위수 수준(0.5~0.9) 연속 전환. 상수 민감도 표 포함
src/plot_2024.py        2024 여름 주간 추적 그래프
outputs/                예측·지표 CSV, 그림
```

실행:

```bash
python src/build_features.py
python src/backtest.py M        # 월말 원점 (KREI 익월 전망과 비교 가능)
python src/backtest.py W        # 주간 원점
python src/anomaly_model.py M
python src/anomaly_model.py W
python src/all_data_model.py M   # 전체 데이터 변형 (backtest·anomaly 결과 CSV가 있어야 병합 비교)
python src/trigger_quantile.py M # 방출 소진 트리거 (backtest_predictions.csv 의 원점 집합 사용, Chronos-2 재계산)
python src/plot_2024.py
```

## 설계 요점

- **타깃**: log(향후 28일 평균가격) − 기준점. 월말 원점이면 익월 평균과 거의 같음.
- **고랭지 기상**: 평창(AWS 526)·태백(216)·정선군(217)·강릉(105) 평균. 2010~2019 일자별 평년 대비 편차,
  30°C 이상 일수, 폭염일, 열대야, 50mm 이상 강우일, 강수 편차 (7/14/30/60일 창).
- **수급**: 반입량 전년비, 모멘텀, 정부 방출 30/60일 합.
- **계절 정상치 모형**: 직전 5년 같은 창의 평균을 정상치로 두고 편차를 예측. 선형·약한 규제라
  2024-08의 학습범위 밖 폭염(+3.5°C, 30일 중 24일 30°C↑)을 외삽할 수 있음. 트리 모형은 범위 밖에서 평탄.
- 누수 방지: 학습 표본의 타깃 창 종료일 ≤ 원점. 평가는 2016~2025 확장창.

### 단변량 기준모형(Chronos-2·MSTL)에서 알게 된 것

- 2010~ 월평균 시계열만 보는 Chronos-2 제로샷·MSTL이 2024-09를 −13~−18%로 따라간다. 가격만 ridge −37%는 "가격 정보의 한계"가
  아니라 **lp28 기준점 + 강한 규제가 평균회귀로 끌어당긴 결과**였다. 8월 하순 상승 모멘텀을 추세 외삽하는 모형은 급등 절반 이상을 잡는다.
- 대신 추세 외삽은 비용이 크다. 2025-08(급등 없던 해) MSTL +32~35%, 2024-10 하락 전환 +45~60%. 전체 MAPE도 17.9~20.9%로 가격만 ridge(15.1%)보다 나쁘다.
- 기상 모형의 실제 기여를 재평가해야 한다. 계절편차 ridge −16%는 MSTL+ETS −13%와 비슷한 수준이고, 급등 없던 해 과대(+21%)도 비슷하다.
  다음 비교의 기준선은 가격만 ridge가 아니라 Chronos-2·MSTL이어야 한다.

### 전체 데이터 피팅에서 알게 된 것

- **두 기준을 동시에 만족하는 모형은 없다.** 2024-09 −10% 이내는 all 계절편차 ridge(−4%)만 달성했으나 전체 MAPE 19.5%로 가격만 ridge(15.1%)보다 나쁘고,
  급등 없던 2025-08을 +35%, 2022-08을 −62%로 틀린다. 반대로 전체 지표 최선인 all LightGBM(13.9%)은 2024-09를 −31%로 놓친다.
- **−4%는 다중공선성의 우연한 상쇄다.** 2024-08-31 기여 분해: 전체 관측소 폭염일 +0.90, 준고랭지 폭염일 −0.34/−0.34, 고랭지 폭염일 −0.29.
  같은 방향의 폭염 변수들이 반대 부호 계수를 받아 상쇄되고 있다. 2025-08-31에도 전체 관측소 폭염일이 +1.03을 주지만 다른 항이 상쇄해 −2%가 된다.
  **90일 누적 폭염은 2025년(57일)이 2024년(54일)보다 많다** → 폭염 누적량만으로는 급등 해와 비급등 해를 가르지 못한다.
- 피처를 늘리면 선형 모형은 급격히 나빠지고(all ridge 21.9%) 트리는 조금 좋아진다(13.9~14.5%). 급등 추종에는 어느 쪽도 도움이 안 된다.
- Chronos-2에 과거 공변량(기상·반입·정부방출)을 넣어도 2024-09는 −17%(제로샷 −18%)로 변화 없고 전체 지표는 나빠진다(17.9→19.4%).
- 결론: **데이터 양이 아니라 2024와 2025를 가르는 변수의 부재가 병목**이다. 두 해 모두 고랭지 폭염은 극심했으나 2025년은 급등하지 않았다.
  후보는 산지 작황·정식 지연(준고랭지 2기작)·재배면적처럼 CABIS 스냅숏에 없는 정보다. 다음 작업은 피처 추가가 아니라 그 변수를 찾는 일.

## 비축 방출 소진 트리거 → Chronos-2 분위수 전환 (2026-10-07, `src/trigger_quantile.py`)

가격 이력만 보는 Chronos-2는 2024-09를 중위수 −18%, 0.9 분위수 +6%로 예측한다. "가격이 오르는데 정부 방출이 급감한다"(비축 여력 소진 →
평균회귀 붕괴)를 원점 당일까지의 aT 일별 방출(`at_gov_daily.csv`, 2021~)과 7일 가격 변화로 판정해, 그 심각도(0~1)에 따라 점예측으로 쓰는
분위수 수준을 0.5 → 0.9로 연속 조정한다. 심각도 = (직전 2주 방출이 활발했는가) × (최근 7일 방출이 얼마나 급감했는가) × (7일 가격 상승 폭).
상수: 300 t/주, 50% 감소, +10% 상승이면 각 1. **규칙 형태와 상수는 2024-08을 보고 정했다(사후 설계).**

월말 원점 2021~2025(n=60), Chronos-2 분위수는 원점별 재계산(0.1~0.9).

| 모형 | 2024-08-31→9월 | 2025-08-31→9월 | MAE | MAPE | bias | 여름 MAPE(n=20) |
|---|---|---|---|---|---|---|
| Chronos-2 중위수 | −18% | −13% | 1,807 | 17.9% | −729 | 19.7% |
| **트리거 연속 분위수** | **+0.4%** | −12% | **1,697** | **17.3%** | −599 | **18.6%** |
| 트리거 이진(0.5↔0.9) | +6% | −13% | 1,760 | 17.7% | −631 | 19.1% |
| 항상 0.9 분위수 | +6% | +14% | 2,935 | 35.8% | +2,676 | 35.0% |

- 발동: 심각도>0.5는 **2024-08-31 한 건**(0.84, 분위수 0.84). 0.2~0.5 부분 발동 3건(2024-02 0.45, 2025-01 0.39, 2023-07 0.21)은 모두 과소 예측을 줄이는 방향으로 작동(−16→−8%, −10→−2%, −30→−26%).
  2025-08은 0.03으로 꺼짐(거짓 경보 없음). 2022-08(방출 증가 국면)·2024-09(방출 0) 은 꺼져 각각 −32%·−31% 그대로.
- **상수 민감도**(300/0.5/0.10을 150~600 / 0.3~0.7 / 0.05~0.20로 27조합): MAPE 17.3~18.0%로 전부 중위수(17.9%)와 비슷하거나 낫고,
  2024-09 오차는 −12~+6%, 2025-08은 −11~−12%로 고정. 이진 규칙(임계 조금만 완화하면 2024-02·2025-07 등 거짓 경보)보다 훨씬 안정적.
  `outputs/trigger_quantile_sensitivity.csv`.
- 한계: 강한 발동 사례 1건, aT 자료 5개년. Chronos 계열 전체 MAPE(17.3%)는 여전히 가격만 ridge(15.1%)보다 나쁘므로 성공 기준 둘째 항은 미충족.
