### ③ 현재 상태 (월말 원점, 2026-10-07 실행)
- **트리거 연속 분위수(월말)**: 2024-08-31→9월 **+0.4%**(중위수 −18%), 2025-08 −12%(거짓 경보 없음), MAPE 17.9→**17.3%**, 여름 19.7→18.6%. 심각도>0.5 발동 1건(2024-08, 0.84). 상수 27조합 전부 MAPE 17.3~18.0%, 2025-08은 −11~−12% 고정 → 이진 규칙보다 안정.
- **트리거(주간)**: 작동 안 함. MAPE 15.4→15.7%, 여름 17.7→18.6%. 2024-09-01/08/15는 잡지만 2022-09-18·2023-08-27·2023-09-10·2025-08-03 거짓 경보(추석 전후 방출 중단, 주간 잡음). 창 확대 설계는 2024 재참조라 멈춤.
- Chronos 계열 MAPE(17.3%)는 가격만 ridge 15.1%보다 여전히 나쁨 → 성공 기준 둘째 항 미충족.
- 2024-08-31→9월: all 계절편차 ridge **−4%**(유일하게 −10% 이내) / all 계절편차 희소 −12% / all LightGBM −31% / all HGB −27% / all ridge −34% / Chronos-2+공변량 −17%.
- 전체 MAPE(2021~2025, n=60): all LightGBM **13.9%**(최선, 여름 14.8%) / all HGB 14.5% / all 계절편차 희소 17.6% / all 계절편차 ridge 19.5% / Chronos-2+공변량 19.4% / all ridge 21.9%.
- **두 성공 기준을 동시에 만족하는 모형 없음.** −4%는 전체 관측소 폭염일(+0.90)과 준고랭지·고랭지 폭염일(−0.34/−0.34/−0.29)의 반대 부호 상쇄 → 다중공선성의 우연. 2025-08은 +35%, 2022-08은 −62%.
- **핵심 사실**: 고랭지 90일 누적 폭염일 2025년 57 > 2024년 54, 90일 기온편차 2025 +2.99°C > 2024 +2.54°C. 그런데 2025-09은 급등 없음(13,344원). 폭염 누적량만으로는 두 해를 못 가른다.

### ⑤ 함정
- 원격 저장소는 **공개**다. CABIS 내부 경로·실명·API 키·미발간 자료 본문을 올리지 않는다.
- 트리 모형(HGB) 수치는 실행마다 ±2~3%p → 원고에 넣을 때 시드·실행 일자 고정, 표 주에 기록.
- 2024-09 한 점만 보고 설계를 바꾸지 않는다. 2020-09·2022-09·2025-08을 같은 표에.
- `tools/style_rules_local.py`의 `PLACEHOLDERS_IGNORE`가 켜져 있어 `[미작성`·`[미정`은 검산에서 통과한다 — 집필 시작 후 반드시 비운다.
- 한글이 든 여러 줄 파이썬을 Bash heredoc으로 고치면 `\n`이 깨진다 → Edit 도구로.
- 논문 폴더 `side-notes/`에 "Chronos-2 배추 가격 예측 연구 따라가기 가이드"(10-03)가 있다. 이 프로젝트에 참고가 되지만 논문 폴더는 이 세션의 작업 디렉터리가 아니므로, 필요하면 사용자에게 그 파일을 가져와 달라고 한다(논문 세션에서는 격리 구역).
