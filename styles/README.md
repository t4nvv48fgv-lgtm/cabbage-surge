# styles

- `citation.csl` — 인용 스타일 파일. 타깃에 맞는 CSL을 여기에 둔다.
  - IEEE / APA / Nature / Chicago 등: https://www.zotero.org/styles 에서 내려받아 `citation.csl`로 저장.
- `reference.docx` — (선택) Pandoc docx 서식 템플릿. `pandoc ... --reference-doc=styles\reference.docx` 로 사용.

※ CSL/템플릿 파일 다운로드는 사용자 승인 후 진행한다 (AGENTS.md 외부 행위 규칙).
