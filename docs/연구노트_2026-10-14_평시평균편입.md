### 평시 모형이 `daily_features`를 쓰는 방식 (종전과 같음, `src/backtest.py`)

- **타깃**: `y_chg = y_lp_fwd28 − lp28`. `y_lp_fwd28`은 다음 날부터 28일 동안 로그가격의 평균(거래일만), `lp28`은 최근 28일 로그가격 평균. 예측가격 = exp(lp28 + 예측한 y_chg).
- **성적 계산에 쓰는 실제값**: `y_price_fwd28_true`(같은 28일의 가격 평균). 로그 평균과 가격 평균은 조금 다르다.
- **재료 47개**: 가격 15(`PRICE_FEATS`), 반입량 4(`SUPPLY_FEATS`), 기상 26(`WX_FEATS`: 고랭지 4곳 `H_*` 20개, 가을 주산지 9곳 `L_*` 6개), `summer`, `month`.
- **학습 줄 풀**: 거래일이고 타깃과 재료 45개가 모두 있는 줄. 솎기 전 4,439줄(2012-01-11 ~ 2026-09-10).
- **미래 정보 차단**: 학습 줄의 날짜 + 28일 ≤ 원점인 줄만. 재료는 그 줄 당일까지의 정보.
- **여름 특화**: 원점이 6~9월이면 6~9월 줄만으로 학습(`wx_hgb_summer`). 그 밖의 원점에서는 전체 줄로 학습하므로 `wx_hgb`와 같은 값이다.
- **모형 사양**: `HistGradientBoostingRegressor(max_iter=300, learning_rate=0.04, max_depth=4, min_samples_leaf=25, l2_regularization=1.0, random_state=0)`.
- **솎기**: 풀에서 세 줄에 하나(`iloc[::3]`). 종전에는 첫 줄부터만 뽑았다(시작점 0).

원점별 학습 줄 수(전체 줄 / 그중 6~9월 줄 / 마지막 학습 줄 날짜), 시작점 0·1·2 순.

|---|---|---|---|
| 2021-08-31 | 967 / 319 / 2021-07-31 | 967 / 317 / 2021-08-02 | 967 / 318 / 2021-08-03 |
| 2023-06-30 | 1,153 / 369 / 2023-06-01 | 1,153 / 367 / 2023-06-02 | 1,152 / 367 / 2023-05-31 |
| 2025-08-31 | 1,372 / 453 / 2025-07-31 | 1,372 / 452 / 2025-08-01 | 1,371 / 450 / 2025-07-30 |
| 2026-07-31 | 1,461 / 477 / 2026-07-02 | 1,461 / 476 / 2026-07-03 | 1,460 / 474 / 2026-07-01 |

세 벌은 줄 수가 같고(차이 0~3줄) 날짜가 하루씩 어긋난 것뿐이다.

### 바꾸지 않은 것

- `src/build_features.py`, `src/backtest.py`, `src/anomaly_model.py`: 손대지 않았다. 평가 설계(원점 집합, 타깃 정의, 누수 차단 규칙)도 그대로다.
- 평시 모형의 재료·사양·학습 규칙: 그대로다. 달라진 것은 "같은 학습을 세 번 하고 평균한다"뿐이다.
- 대표 모형, 겨울 모형, 가격만 모형: 시작점 0 그대로다.
- 게이트 판정(`gate_calm`), 수준 조정 계수, 9월 고온 층의 식: 그대로다.

### 평균의 정의

`calm_avg = exp( lp28 + (ŷ₀ + ŷ₁ + ŷ₂) / 3 )`, ŷₖ는 시작점 k로 솎은 줄로 학습한 모형의 예측(로그 변화). 가격으로는 세 예측의 기하평균이다. case31의 '평시 평균'과 같은 정의다.

- 모든 원점(여름 밖 포함)에서 계산한다. 최종값에 쓰이는 것은 평시로 판정된 여름 원점뿐이다(월말 14개, 주간 65개).

### 해석

1. **평균 성적은 시작점 덕이 아니었다.** 세 벌 평균으로 바꿔도 월말 11.38 → 11.39%다. 종전 성적이 우연히 좋은 시작점에서 나온 것이었다면 평균에서 눈에 띄게 나빠졌을 것이다.
2. **달별 값은 종전이 조금 유리했다.** 바뀐 15개 원점 가운데 5개가 좋아지고 10개가 나빠졌다. 좋아진 폭은 2023-06-30이 12%p로 가장 크고, 나빠진 폭은 1~6%p다. 시작점 0이 세 벌 가운데 가장 맞은 원점이 많았다는 뜻이고, 그 차이는 우연으로 본다(세 벌은 정보가 같다).
3. **편입으로 얻은 것은 정확도가 아니다.** 얻은 것은 "누구도 고른 적 없는 선택(시작점)이 달별 수치를 10%p 넘게 좌우하는 상태"를 없앤 것이다.
4. **급등 해의 값은 건드리지 않았다.** 2022-08-31·2024-08-31은 경보 원점이라 대표 모형이 예측한다. 성공 기준 달(2024-09 −6%)은 그대로다.
5. **2025년 9월의 과대 예측이 +15 → +20%로 커졌다.** 급등이 없던 해에 높게 보는 약점이 더 분명해졌다. 종전의 +15%는 세 벌(+15, +30, +14) 가운데 낮은 쪽이었다.
6. **주간이 15.15 → 15.02%로 좋아진 것은 강조하지 않는다.** 표본이 많아 평균 효과가 드러난 것일 수 있으나, 월말에서는 같은 효과가 보이지 않았다.

### 쓰지 않기로 한 해석

- "안정화로 성능이 개선됐다": 평균 성적은 같고 달별 값의 3분의 2가 나빠졌다.
- "평시 모형이 안정적이다": 솎기 시작점 한 가지에 대해서만 평균했다. 나무 깊이·학습률·난수 씨앗은 바꿔 보지 않았다.
- 종전 문서의 "2021년 9월 +2%", "2023년 9월 −3%", "2025년 9월 +15%": 시작점 0에서만 나오는 값이라 현재 값으로 인용하지 않는다.

## 9. 한계와 미확인 사항

1. **솎기 시작점 한 가지에 대한 안정화다.** 솎기 간격(3)을 바꾼 경우, 나무 모형의 깊이·학습률·잎 크기·난수 씨앗을 바꾼 경우는 보지 않았다.
2. **로그 평균을 쓴 것은 case31의 정의를 따른 것이다.** 가격의 산술평균과 견줘 보지 않았다.
3. **같은 구간을 본 뒤의 결정이다.** 평균 성적이 같다는 것을 2021~2025년에서 확인한 뒤 넣었다. 다만 고른 것은 시작점 하나가 아니라 "셋을 다 쓴다"이고, 더 좋은 숫자가 나온 변형('평시 전부' 11.26%)은 넣지 않았다.
4. **2026년 10월 전망이 10월 실적 일부를 본 뒤에 바뀌었다**(8,766 → 8,778원. 10/1~10/8 실제 평균 11,023원, 거래일 7일). 9월 고온 층의 사전 판정 규칙은 그대로 두고, **판정 경계는 10-13에 고정한 8,319원을 쓰기로 했다. 이것은 작업자 판단이며 사용자 확인이 필요하다**(새 값으로 계산한 중간은 8,325원).
5. **게이트가 평시로 본 해에 급등이 오는 경우**에 세 벌 평균이 한 벌보다 못 따라가는지는 확인할 표본이 없다(2021~2026년에 그런 해가 없음).
