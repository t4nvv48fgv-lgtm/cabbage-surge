### 설계 요점
- **타깃**: `y_lp_fwd28` = log(원점 다음날부터 28일간 거래일 평균가격). 월말 원점이면 익월 평균과 거의 동일 → KREI 익월 전망과 비교 가능.
- **모형 타깃**: `y_chg = y_lp_fwd28 − BASE` (BASE=lp28 최근 28일 로그평균, 또는 lp7). 예측값 = exp(BASE + ŷ).
- **피처군** (`backtest.py` 상단 상수):
  - `PRICE_FEATS` 15개: lp7/28/90, 1·2년 전 같은 창, 모멘텀, 전년비, 변동성, 7·14일 변화, 연·반년 주기 sin/cos.
  - `SUPPLY_FEATS` 6개: 반입량 lq7/lq28, 전년비, 모멘텀, 정부방출 30/60일 합.
  - `WX_FEATS` 26개: 고랭지(H_) 30°C↑일수 14/30/60, 33°C↑, 50mm↑ 강우일, 열대야, 폭염일, 강수합, 기온·강수 평년편차(2010~2019 일자별 15일 평활 기준), 가을주산지(L_) 일부.
  - `SPREAD_FEATS` 5개: 상품/중품·특품/상품 가격비. **검증 결과 노이즈라 기본 제외**(2024년엔 9월에야 벌어져 선행성 없음, 2023-08엔 높았지만 가격 안 올랐음).
- **누수 차단**: 학습 표본은 거래일 중 3일 간격 추출, `index + 28일 ≤ 원점`인 행만. 평년 기후값은 2010~2019 고정(2016~ 평가 구간과 일부 겹침 — 기후 평년치라 영향 미미하다고 판단했으나 엄밀히는 확장창으로 바꾸는 게 맞음, 미결).
- **계절 정상치 모형**(`anomaly_model.py`): 정상치 = 직전 5년 같은 창의 lp 평균(`norm7/norm28/norm_fwd`, 364일 단위 shift). 타깃 = `y_lp_fwd28 − norm_fwd`. 피처 = 현재 편차(`cur_anom7/28`), 기상 편차, 반입 전년비, 정부방출. Ridge alpha 1.0(전체) / 0.3(희소) / Huber. `*_summer` 변형은 원점이 6~9월일 때 여름 원점 표본만으로 학습.

### 5-4. 해석
1. 가격만 쓰는 모형 −37%는 KREI 두 연구의 한계를 그대로 재현한 것. 벤치마크로서 의미 있음.
2. 고랭지 폭염 피처가 가장 큰 개선 요인. 선형(ridge)이 트리(HGB)보다 급등 정점에서 낫고, 전체 MAE는 트리가 낫다 → 두 특성을 합치는 설계가 필요.
3. 모든 모형이 여름에 음(−)의 bias. 규제가 평균회귀 쪽으로 당기기 때문. 2024-09 과소 −16%는 (a) 공급충격→가격의 비선형(탄력성), (b) 준고랭지 2기작 정식 지연 같은 산지 정보 부재가 원인으로 추정.
4. 10월 과대는 가을배추 출하 전환 신호가 없어서다. 2024는 10월에도 20,324원으로 높게 유지됐지만 2020·2022는 급락했다 — 두 패턴을 가르는 변수를 아직 못 찾음.

## 6. 시도했지만 효과 없었던 것 (반복 금지)

## 7. 다음 작업 후보 (우선순위 순)

1. **공급충격→가격 변환 레이어(구조 접근)**: KREI 월보 `krei_baechu_monthly_series` 시트2의 여름배추 단수·생산량 전망(2024-06호 생산 −2.9% → 2024-10호 −12.0%)과 CABIS `market/outputs/regime_results.xlsx` 여름 국면 계수(cutoff 08-29, β1 −0.41, β2 +0.21)를 써서 "폭염 누적 → 단수 감소율 → 가격 상승률" 식의 반구조 모형. 2022~2025 4개년밖에 없으므로 추정이 아니라 캘리브레이션·시나리오 용도.
2. **하락 전환 신호**: 가을배추 주산지 정식(8월 하순~9월 상순) 이후 적산온도, 10월 반입량 전년비, 준고랭지 2기작 출하 시점 proxy(정선·평창 9월 하순 기온). `LOWLAND_AUTUMN` 피처의 효과를 먼저 ablation으로 확인.
3. **선형+트리 결합**: 트리로 평시 예측, 선형 편차모형의 기상 외삽분을 가산(또는 기상 편차가 학습범위 밖일 때만 선형으로 전환하는 게이팅).
4. **분위수·정합예측**: 0.8/0.9 분위수 ridge(sklearn `QuantileRegressor`)로 급등 위험 밴드. Chronos 연구의 0.9분위수 접근과 비교 가능.
5. **엄밀성**: 기후 평년값을 확장창으로, 하이퍼파라미터는 2016~2023으로 고르고 2024~2025에 검증. 2024-09 한 점 과적합 경계.
6. **운영화**: 원격 저장소 생성(맥 전환 대비), 주간 자동 실행 스크립트, 결과표 자동 갱신.
